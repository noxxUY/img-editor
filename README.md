# noxx's IMG Editor

Browser-based IMG archive editor for the classic GTA trilogy with 3D model viewer and texture previewer. Nothing leaves your machine.

![Landing, Vice City palette](docs/screenshot-home-vc.png)
![Model viewer, San Andreas](docs/screenshot-model.png)
![Texture viewer, San Andreas](docs/screenshot-texture.png)

The game is detected from the archive and the colors follow it:

![Landing, San Andreas palette](docs/screenshot-home-sa.png)
![Landing, GTA III palette](docs/screenshot-home-iii.png)

## Getting started

```bash
npm install
npm run dev
```

Drop `gta3.img` on the page. GTA III and Vice City archives use `.img` + `.dir` — drop both together.
